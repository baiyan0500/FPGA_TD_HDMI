# 系统架构

## 1. 顶层数据流

```
                    ┌──────────────────── TF 卡（SPI）────────────────────┐
                    │                                                     │
              ┌─────▼─────┐        ┌──────────┐      ┌─────────┐          │
              │ sd_card_top│───────▶│ bmp_read │─────▶│ scaler  │          │
              │ 扇区读/命令│        │ BMP 解析 │      │→640×480 │          │
              └─────┬─────┘        └──────────┘      └────┬────┘          │
                    │ 总线仲裁                            │ 100MHz          │
                    │                              ┌──────▼──────┐        │
                    │                              │ 写异步 FIFO  │        │
                    │                              └──────┬──────┘        │
                    │                                     │ 125MHz          │
                    │                              ┌──────▼──────┐        │
                    │                              │ SDRAM 双缓冲 │        │
                    │                              │ BUF0 / BUF1 │        │
                    │                              └──────┬──────┘        │
                    │                                     │ 25MHz           │
                    │                              ┌──────▼──────┐        │
                    │                              │ video_delay │        │
                    │                              └──────┬──────┘        │
                    │                                     ▼                │
                    │                      亮度/对比度 → 转场 → OSD 叠加     │
                    │                                     │                │
                    │                              ┌──────▼──────┐        │
                    │                              │ HDMI 1.4b TX │───▶ TMDS
                    │                              └──────▲──────┘        │
                    │                                     │ I2S/ACR         │
                    │        ┌──────────┐   ┌─────────────┴──┐            │
                    └───────▶│sd_card_wav│──▶│ wav_i2s_source │            │
                             │ RIFF 解析 │FIFO│ ASRC → 48kHz   │            │
                             └──────────┘   └────────────────┘            │
                                                                          │
  按键/拨码 ──▶ ctrl（video_clk）──▶ 亮度/对比度、转场、轮播、音频/频谱开关   │
  UART 115200 ──▶ slogan_ctrl（50MHz）──▶ OSD 标语滚动                      │
  I2S 采样 ──▶ audio_spectrum（video_clk）──▶ 32 段频谱 / 峰值音量条 ───────┘
```

关键点：

- BMP 与 WAV 共用 SD 总线，由 `sd_card_bmp` 内仲裁器按扇区边界切换，避免读事务交叉
- 图片像素经异步 FIFO 跨到 125MHz 写入 SDRAM；显示侧按帧从另一缓冲区读出，实现双缓冲
- 转场模块通过 `fade_req`/`fade_swap` toggle 与图片装载状态机握手，切图在 VS 边界生效
- WAV 优先，解析失败时自动回退到内置测试音

## 2. 时钟域

| 时钟 | 频率 | 来源 | 主要负载 |
|---|---|---|---|
| `clk` | 50 MHz | 板载晶振 R7 | POR、UART、PLL 参考 |
| `sd_card_clk` | 100 MHz | `sys_pll` C0 | TF SPI、BMP 解析、SD 侧状态机、WAV 读扇区 |
| `ext_mem_clk` | 125 MHz | `sys_pll` C1 | SDRAM 控制器、帧缓存调度 |
| `ext_mem_clk_sft` | 125 MHz / 180° | `sys_pll` C2 | SDRAM 采样时钟 |
| `video_clk` | 25 MHz | `video_pll` C0 | 像素时序、OSD、转场、按键控制、频谱 |
| `hdmi_5x_clk` | 125 MHz | `video_pll` C1 | TMDS 10:1 串行化 |
| `audio_mclk` | 12.295082 MHz | `PLL_HDMI_AUDIO` C2 | I2S 主时钟、WAV ASRC、音频 FIFO 读 |

> `PLL_HDMI_AUDIO` 的 12.295082MHz 是 PLL 可实现的近似值，代码/注释按 12.288MHz 处理；ASRC 以 48kHz 为目标做分数重采样。

## 4. 存储与缓冲

- **SDRAM**：2M × 32bit，地址 21 位
- **帧缓冲**：`BUF0 = 0`，`BUF1 = 307200`（640×480 字）
- **像素格式**：SDRAM 中每字存 24bit RGB 于 `[31:8]`，`[7:0]` 补零；写入时 `WRITE_V_FLIP=1` 做垂直翻转
- **双缓冲**：`write_buf_idx` / `disp_buf_idx` 分离，写完整帧后切换显示缓冲；转场在 VS 边界交换
- **WAV FIFO**：16bit × 256 深异步 FIFO（100MHz 写 / audio_mclk 读）
- **帧写/读 FIFO**：`frame_read_write` 内部异步 FIFO 完成 100↔125MHz、125↔25MHz 跨域

## 5. 跨时钟域处理

| 信号 | 方式 |
|---|---|
| BMP 像素 100→125MHz | 异步 FIFO |
| 帧写完成 `frame_write_finish` | ext_mem_clk 下单拍转 toggle，100MHz 域同步 |
| 帧读数据 125→25MHz | `frame_read_write` 读 FIFO，`read_req/ack` 握手 |
| WAV PCM 100→audio_mclk | 异步 FIFO（FWFT） |
| 控制电平（自动轮播/暂停/亮度等） | 2 级触发器同步（准静态电平） |
| `display_valid` / `sd_ready` / `scan_done` / `img_count` | 2 级同步（上电后准静态） |
| 转场 `fade_req` / `fade_swap` | toggle 握手 |
| UART 标语更新 | 50MHz 域 toggle → video_clk 域锁存 |
| 音频 ASRC 参数 | `active` 前置稳定，2 级同步后使用 |

## 6. 复位

`top` 内 POR：等待 `sys_pll_lock`、`video_pll_lock`、`audio_pll_lock` 同时有效后，连续计数 20ms（50MHz）再释放 `rst_all`；释放后锁存，忽略后续 PLL 抖动，避免运行中随机复位。

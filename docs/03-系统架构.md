# 系统架构

## 1. 顶层数据流

```
                    ┌──────────────────── TF 卡（SPI）────────────────────┐
                    │                                                     │
              ┌─────▼─────┐        ┌──────────┐      ┌─────────┐          │
              │ sd_card_top│───────▶│ bmp_read │─────▶│ scaler  │          │
              │ 扇区读/命令│        │ BMP 解析 │      │→640×480 │          │
              └─────┬─────┘        └──────────┘      └────┬────┘          │
                    │ 总线仲裁                            │ 100MHz          │
                    │                              ┌──────▼──────┐        │
                    │                              │ 写异步 FIFO  │        │
                    │                              └──────┬──────┘        │
                    │                                     │ 125MHz          │
                    │                              ┌──────▼──────┐        │
                    │                              │ SDRAM 双缓冲 │        │
                    │                              │ BUF0 / BUF1 │        │
                    │                              └──────┬──────┘        │
                    │                                     │ 25MHz           │
                    │                              ┌──────▼──────┐        │
                    │                              │ video_delay │        │
                    │                              └──────┬──────┘        │
                    │                                     ▼                │
                    │                      亮度/对比度 → 转场 → OSD 叠加     │
                    │                                     │                │
                    │                              ┌──────▼──────┐        │
                    │                              │ HDMI 1.4b TX │───▶ TMDS
                    │                              └──────▲──────┘        │
                    │                                     │ I2S/ACR         │
                    │        ┌──────────┐   ┌─────────────┴──┐            │
                    └───────▶│sd_card_wav│──▶│ wav_i2s_source │            │
                             │ RIFF 解析 │FIFO│ ASRC → 48kHz   │            │
                             └──────────┘   └────────────────┘            │
                                                                          │
  按键/拨码 ──▶ ctrl（video_clk）──▶ 三层功能：图片 / 自动 / 视频
  SW4 ──▶ ctrl 2 级同步 ──▶ osd_layer 全屏告警层（压暗染红 + 上下警示带 + 告警卡片，最高显示优先级）
  UART 115200 ──▶ slogan_ctrl（50MHz）──▶ OSD 标语滚动 + 弹幕               │
  I2S 采样 ──▶ audio_spectrum（video_clk）──▶ 32 段频谱 / 峰值音量条 ───────┘

  视频通路（层3）：
  egv_reader（100MHz）──▶ video_frame_fill（2 倍放大）──▶ SDRAM BUF2/BUF3
        └──▶ egv_audio_fifo ──▶ I2S ──▶ HDMI 音频
```

关键点：

- BMP 与 WAV 共用 SD 总线，由 `sd_card_bmp` 内仲裁器按扇区边界切换，避免读事务交叉
- 视频客户端在扇区边界接管总线：BMP/WAV 均无在途扇区才交出，撤销时等当前批次结束；播放期间 BMP 装载暂停、WAV 让出总线。写完成按应答时锁存的归属（`wr_fin_split`）分别回送视频/BMP 的完成脉冲
- 图片像素经异步 FIFO 跨到 125MHz 写入 SDRAM；显示侧按帧从另一缓冲区读出，实现双缓冲
- 转场模块通过 `fade_req`/`fade_swap` toggle 与图片装载状态机握手，切图在 VS 边界生效
- WAV 优先，解析失败时自动回退到内置测试音
- 视频帧同样走 SDRAM 双缓冲（BUF2/BUF3），每帧只重写中间 296 行，上下黑边初始化一次
- EGV 容器的位置由扫描魔数确定（扫描按头内文件长度直接跳过容器），播放时再读 1 个扇区头装载段表，因此重新封装/搬动视频一般无需重烧 bit

## 2. 时钟域

| 时钟 | 频率 | 来源 | 主要负载 |
|---|---|---|---|
| `clk` | 50 MHz | 板载晶振 R7 | POR、UART、PLL 参考 |
| `sd_card_clk` | 100 MHz | `sys_pll` C0 | TF SPI、BMP 解析、SD 侧状态机、WAV 读扇区 |
| `ext_mem_clk` | 125 MHz | `sys_pll` C1 | SDRAM 控制器、帧缓存调度 |
| `ext_mem_clk_sft` | 125 MHz / 180° | `sys_pll` C2 | SDRAM 采样时钟 |
| `video_clk` | 25 MHz | `video_pll` C0 | 像素时序、OSD、转场、按键控制、频谱 |
| `hdmi_5x_clk` | 125 MHz | `video_pll` C1 | TMDS 10:1 串行化 |
| `audio_mclk` | 12.295082 MHz | `PLL_HDMI_AUDIO` C2 | I2S 主时钟、WAV ASRC、音频 FIFO 读 |

> `PLL_HDMI_AUDIO` 的 12.295082MHz 是 PLL 可实现的近似值，代码/注释按 12.288MHz 处理；ASRC 以 48kHz 为目标做分数重采样。

## 3. 模块职责

| 模块 | 时钟域 | 职责 |
|---|---|---|
| `top` | 多域 | 顶层连接、POR 复位、时钟/PLL、跨域同步 |
| `sd_card_bmp` | 100 MHz | SD 初始化、BMP/WAV 扫描、读写总线仲裁、装载状态机、自动轮播 |
| `sd_card_cmd` / `sd_card_sec_read_write` | 100 MHz | SD 命令与扇区读写 |
| `bmp_read` | 100 MHz | BMP 头解析、像素流输出、超时/损坏文件退出 |
| `scaler` | 100 MHz | 任意分辨率→640×480 最近邻缩放（行缓存 + DDA） |
| `sd_card_wav` | 100 MHz | RIFF/fmt/data 解析、PCM 流式读取、循环、暂停、跨域 FIFO 写 |
| `wav_i2s_source` | 12.295 MHz | ASRC 线性插值到 48kHz、I2S 帧样本输出 |
| `frame_read_write` | 125/25 MHz | SDRAM 帧缓存双缓冲、读/写请求与异步 FIFO |
| `video_timing_data` / `video_delay` | 25 MHz | 640×480 时序生成、按像素取数、行延迟 |
| `brightness_contrast` | 25 MHz | RGB 亮度/对比度 5 档调节 |
| `transition_ctrl` | 25 MHz | 淡入淡出 / 右擦除 / 左擦除 / 下滑入 |
| `osd_layer` | 25 MHz | 上下信息栏、时间戳、启动面板、标语、频谱/音量条、弹幕与资源面板合成；SW4 全屏告警层（最高显示优先级） |
| `slogan_ctrl` / `uart_rx` | 50 MHz | 115200 8N1 接收、按行解析标语/滚动方向，同时投递弹幕 |

| `danmaku_osd` | 25 MHz | 两条轨道、逐字变色的弹幕滑屏，toggle 握手跨域 |

| `audio_spectrum` | 25 MHz | 32 段 Goertzel 频谱（N=1024 Bartlett 窗，每窗清 s2，47Hz~16kHz，dB 映射），状态存于 2 片 BRAM |
| `egv_reader` | 100 MHz | 扫描定位 + 运行时读头：4 段段表/整文件连续/编译期表三路回退，拆分视频字节与音频字节、末帧停机 |
| `video_frame_fill` | 100 MHz | RGB565 行缓冲、2 倍放大、写 SDRAM 中间 296 行 |
| `egv_audio_fifo` | 100→12 MHz | 视频音轨字节流重排为 s16 立体声采样 |
| `wr_fin_split` | 100 MHz | 写完成按应答时锁存的归属分流到 BMP/视频客户端 |
| `I2S_receiver` | 25 MHz | 从 I2S 帧恢复左右声道 PCM，供频谱/音量使用 |
| `hdmi_1_4b_transmitter_core_wrapper` | 多域 | HDMI 视频打包、音频嵌入、ACR、TMDS |
| `sys_pll` / `video_pll` / `PLL_HDMI_AUDIO` | — | 时钟生成 |
| `seg_scan` / `seg_decoder` | 50 MHz | 6 位数码管动态扫描与译码 |

## 4. 存储与缓冲

- **SDRAM**：2M × 32bit，地址 21 位
- **图片帧缓冲**：`BUF0 = 0`，`BUF1 = 307200`（640×480 字）
- **视频帧缓冲**：`BUF2 = 614400`，`BUF3 = 921600`，视频写口偏移 `+92×640`（只覆盖中间 296 行）
- **像素格式**：SDRAM 中每字存 24bit RGB 于 `[31:8]`，`[7:0]` 补零；图片写入时 `WRITE_V_FLIP=1` 做垂直翻转，视频按自顶向下顺序写
- **双缓冲**：`write_buf_idx` / `disp_buf_idx` 分离，写完整帧后切换显示缓冲；转场在 VS 边界交换
- **WAV FIFO**：16bit × 256 深异步 FIFO（100MHz 写 / audio_mclk 读）
- **视频音轨 FIFO**：字节写、16bit FWFT 读，首帧落盘后才放开
- **帧写/读 FIFO**：`frame_read_write` 内部异步 FIFO 完成 100↔125MHz、125↔25MHz 跨域
- **频谱状态**：s1/s2 系数各 32×28bit 存于 DP 9Kb BRAM，替代 1792 个触发器

## 5. 跨时钟域处理

| 信号 | 方式 |
|---|---|
| BMP 像素 100→125MHz | 异步 FIFO |
| 帧写完成 `frame_write_finish` | ext_mem_clk 下单拍转 toggle，100MHz 域同步 |
| 帧读数据 125→25MHz | `frame_read_write` 读 FIFO，`read_req/ack` 握手 |
| WAV PCM 100→audio_mclk | 异步 FIFO（FWFT） |
| 控制电平（自动轮播/暂停/亮度等） | 2 级触发器同步（准静态电平） |
| `display_valid` / `sd_ready` / `scan_done` / `img_count` | 2 级同步（上电后准静态） |
| 转场 `fade_req` / `fade_swap` | toggle 握手 |
| UART 标语更新 | 50MHz 域 toggle → video_clk 域锁存 |
| 弹幕文本/长度/色号 | 50MHz 域 toggle → video_clk 域锁存，video_clk 域 echo 回 ack |
| 视频显示 bank / 视频帧完成 | 2 级同步（准静态，按帧变化） |
| 音频 ASRC 参数 | `active` 前置稳定，2 级同步后使用 |

## 6. 复位

`top` 内 POR：等待 `sys_pll_lock`、`video_pll_lock`、`audio_pll_lock` 同时有效后，连续计数 20ms（50MHz）再释放 `rst_all`；释放后锁存，忽略后续 PLL 抖动，避免运行中随机复位。

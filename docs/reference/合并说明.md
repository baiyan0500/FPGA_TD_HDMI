## 关于 PLL 的 `.ipc` 改动（重要，勿回退）

`sys_pll.v` / `video_pll.v` 是 TD 从同名 `.ipc` **生成**的。本项目 `.al` 引用的是 `.ipc`，
所以只替换 `.v` 不够——TD 下次编译时可能按 `.ipc` 重新生成，把 `extlock` 端口去掉，
导致顶层 `.extlock(sys_pll_lock)` 报"端口不存在"。

`<pll_lock>ENABLE</pll_lock>` 就是生成 `extlock` 端口的开关（对照 `PLL_HDMI_AUDIO.ipc` 可验证：
它有这一项，其生成的 `.v` 就有 `extlock`）。**两个 `.ipc` 里这一项不能删。**

## 与文档的一处刻意偏差

文档写的是"照搬 lab_ex4 的 POR 段"。实际实现把门控条件从 **2 个 PLL 扩展为 3 个**：

```verilog
end else if (sys_pll_lock && video_pll_lock && audio_pll_lock) begin
```

理由：lab_ex4 只有 sys/video 两个 PLL 才那样写；本工程有第三个 audio PLL，音频链路
（`hdmi_audio_tone_i2s_64fs`）跑在 `audio_mclk` 上，必须等它锁定后才能运行。
原 lab_ex5 也只等 `audio_pll_lock`，说明音频 PLL 本就被视为必需。

> ⚠️ 副作用：若将来移除音频链路或音频 PLL 失锁，系统将**一直停在复位**（黑屏无声）。
> 排查时先量 `audio_pll_lock`。

## 上板必验项（未在硬件上验证过）

1. **出图 + 出声**：HDMI 接显示器，应看到 TF 卡图片轮播并听到音阶测试音。
2. **连按 key1 切图 50 次不死机** —— 验证防死锁生效（这是本次合并的主要目的）。
3. **反复上电 5 次** —— 验证 POR 复位生效，不出现花屏/黑屏。
4. **HDMI 接口位置**：官方例程文档写 `HDMI_B`，但 `pin.adc` 里的引脚组 `C3/G5/F1/E1`
   与 `Other/31_hdmi_tx_display_A` 用的是同一组，而 A 例程还额外声明了第二组
   `K1/F5/E3/B3`。**引脚是事实，A/B 标签待上板核对**（详见根目录文档第 9 节）。

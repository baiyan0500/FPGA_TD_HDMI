# HX4S20‑安路FPGA开发板使用手册（HDL版2410）
> 出品：杭州康芯电子有限公司 官网：WWW.KX‑SOC.COM 2025‑04

## 开发板使用注意事项
1. USB口插拔时，首先关闭电源开关，轻轻插拔，并且不要频繁插拔，以免造成接口损坏！
2. 开发板不用时，要关闭电源！
3. 需外接设备和连线时，首先关闭电源，确保外设接插正确，再打开电源！
4. 开发板上的裸露的金属针、孔等，不要随意用手触摸，以免静电导致芯片烧坏和污迹粘上氧化！
5. 开发板上的器件不要随意卸装，以免装配失误导致开发板故障！
6. 开发板发生故障、水迹、异常或无电时，请立即切断电源！
7. 平时开发板不用时，及时收纳，以免落入灰尘，引起故障和寿命；平时准备一个吹尘器，板表面或很久没有使用时，清理灰尘！
8. 开发板应存放于干燥地方，以免潮湿，再开机时引起故障！

## 一、开发板特色
1. HX4S20板核心芯片采用了安路的EG4S系列；
2. 采用板载USB‑JTAG，USB供电：5V、3.3V、2.5V、1.2V；
3. 该板含有基础学习的资源，4按键、4开关、8个数码管、8双色LED、4个独立LED；
4. USB转UART、TF卡、HDMI输入输出口，VGA，千兆网口、蜂鸣器；
5. SPI FLASH 25Q64/16；
6. 标配了2组40芯IO扩展口，提供5V、3.3V电源，每组36个IO口（即18对差分IO），扩展接口兼容市场上大多数扩展板。

### ① FPGA
国产FPGA安路：EG4系列：**EG4S20BG256**
LUTs：19600，RAM：156.8K，BRAMb：1008K，DDR/SDRAM：2M*32。新一代产品，内部资源丰富，可以很好的替代XILINX和ALTERA系列FPGA。此型号为BGA封装，256个引脚。
> BGA封装引脚命名规则：引脚名称由字母+数字的形式，比如H4，J13等。

### ⑤ 电源开关
USB‑JTAG输入5V后经过总电源开关SW，控制开发板整机供电，带保险丝F1；有红色电源指示灯LED14，串联1K电阻。

### ⑥ USB‑JTAG
此USB接口有二个作用：(1)开发板供电口；(2)FPGA编程口。

#### (1)开发板供电系统
USB输入5V进入电源管理系统，产生多路电压：+5V、+3.3V、+2.5V、+1.2V。
- FPGA：3.3V、1.2V
- Ethernet PHY：3.3V、2.5V
- GPIO,HDMI：3.3V、5V
- 按键、LED、数码管、开关、FLASH：3.3V、5V

#### (2)USB‑JTAG编程口
板载Anlogic USB Cable，USB‑B接口，接电脑USB。
- JTAG模式下载.bit到FPGA运行；
- 可将.bin文件烧录至FLASH，实现掉电保存，上电自动加载。
- JTAG信号：TCK、TDO、TMS、TDI直接连接FPGA引脚。

**JTAG接口引脚表**
|信号名称|FPGA引脚|信号名称|FPGA引脚|
| ---- | ---- | ---- | ---- |
|FPGA_TCK|C14|FPGA_TDI|C12|
|FPGA_TMS|A15|FPGA_TDO|E14|

### ⑪ 数码管
- 器件：2组4位一体**共阳极八段数码管（带小数点DP）**；
- 共阳逻辑：段脚输出**低电平点亮段**；位选SEL高电平选通对应数码管；
- 动态扫描：8个数码管段全部并联，SEL分时选通；扫描频率>50Hz消除人眼看到的闪烁；
- **引脚复用**：数码管16个引脚与8组双色LED完全复用。SW6拨码开关选择功能：拨上=数码管，拨下=双色LED。
- DIG[0..7]：a‑g、dp段信号；SEL[0..7]：8个位选信号。

### ⑫ 8组双色LED发光管

### ⑬ SPI FLASH W25Q64
64Mbit SPI FLASH，擦写周期10万次，保存20年；电压2.7‑3.6V；支持SPI、双SPI、四SPI，最高时钟80MHz。

**W25Q64引脚分配**

| ---- | ---- | ---- | ---- |
|FLASH_CS|P8|FLASH_HOLD|R9|
|FLASH_SDO|N8|FLASH_SCLK|M9|
|FLASH_WP|P9|FLASH_SDI|P7|

### ⑭ 蜂鸣器
PNP三极管驱动：BUZZER为**低电平三极管导通，蜂鸣器鸣叫；高电平截止不响**。
SW5乒乓开关：拨上断开蜂鸣器，拨下接通。

**蜂鸣器引脚分配**
|引脚名称|FPGA引脚|
| ---- | ---- |
|BUZZER|H11|

### ⑮ 乒乓开关（拨码开关）
一共6路乒乓开关：
- SW1‑SW4：输入FPGA IO，拨上逻辑1，拨下逻辑0；
- SW5：蜂鸣器使能开关；
- SW6：数码管/双色LED复用选择开关。

**SW1‑SW4引脚**

| ---- | ---- | ---- | ---- |
|SW1|C8|SW2|C7|
|SW3|C6|SW4|C5|

# 功能与操作

## 1. 上电流程

1. 插入已准备素材的 TF 卡，连接 HDMI 显示器/电视
2. 上电后等待三个 PLL 锁定 + 20ms POR，约数百毫秒内出现开机画面
3. 系统扫描 TF 卡前 64MB（扇区 0~131071，4KB 步进，扫满为止），最多记录 16 张 BMP 和第一个 WAV
4. 首张图片写入 SDRAM 完成后，启动面板消失，进入正常播放；WAV 校验通过则自动开始播放
5. 未检测到有效图片时保持黑屏；未检测到有效 WAV 时自动使用内置测试音

## 2. 显示与 OSD

- 输出：640×480@60，HDMI 1.4b，24bit RGB
- 上下信息栏保持原例程布局：顶部状态/标语、底部时间戳与模式信息
- 开机阶段：左中区域显示 `FPGA DISPLAY SYSTEM`，右侧显示 SW/K 功能说明，左侧边框有跑马灯效果；首图提交后恢复常规显示
- 常规 OSD：亮度/对比度档位、转场模式、自动轮播状态、播放计数、音量峰值条、32 段频谱（按开关显示）
- 标语默认 `EG4S20 HDMI PLAYER`，可通过 UART 更新；仅支持 ASCII 字符

## 3. TF 卡与素材要求

### 3.1 扫描方式

工程**按物理扇区扫描**，不依赖 FAT 目录项：

- 在扇区 0~131071（前 64MB）内查找 `BM`（BMP）与 `RIFF/WAVE`（WAV）标识
- 最多加载 16 张 BMP，按物理扇区顺序播放，**不按文件名排序**
- 只使用扫描到的第一个 WAV
- 删除文件后底层扇区数据仍可能存在，因此换图必须使用 `doc/convert/sync_to_sd.py`；它会在删除前把可见 BMP/WAV 清零，`--deep` 可进一步覆盖历史残留扇区

### 3.2 BMP 要求

| 项目 | 要求 |
|---|---|
| 格式 | Windows BMP，未压缩（BI_RGB） |
| 位深 | 24bit |
| 方向 | 仅支持自底向上（正高度）；负高度（自顶向下）会被拒绝 |
| 分辨率 | 宽 ≤1024、高 ≤2047；非 640×480 时由 `scaler` 最近邻缩放到 640×480 |
| 大小 | 单张需落在前 64MB 扫描窗口内 |

推荐直接用 `doc/convert/convert_images_to_bmp.py` 统一转换；默认输出 640×480，加 `--keep-size` 可保留原尺寸（上限 1024×2047）。注意 PNG/JPG 不能直接给固件读取，必须转成 24bit BMP。

### 3.3 WAV 要求

| 项目 | 要求 |
|---|---|
| 编码 | PCM（format=1），16bit |
| 声道 | 单声道或立体声 |
| 采样率 | 8k / 11.025k / 16k / 22.05k / 24k / 32k / 44.1k / 48k |
| 行为 | 解析成功后循环播放；到 data 尾部自动回绕；暂停时冻结读指针，恢复后从断点继续 |
| 回退 | 非 PCM、非 16bit、采样率不支持、无 data 等情况自动回退内置测试音 |

### 3.4 制作与同步

```bash
# 1) 转换图片：把素材放入 input_images/，运行（会先清空 output_bmp 里的旧 BMP）
python doc/convert/convert_images_to_bmp.py
#    想保留 1024 宽度、只转格式：
python doc/convert/convert_images_to_bmp.py --keep-size

# 2) 同步到 TF 卡（假设盘符 E:，默认最多 16 张）
python doc/convert/sync_to_sd.py E:

# 曾经手动删过卡上图片时，先做一次深度清理（较慢）
python doc/convert/sync_to_sd.py E: --deep
```

`sync_to_sd.py` 会清零并删除可见文件、按序号写入新图，避免 FPGA 扫描到残留旧图；写完请**断电重新上电**，固件只在初始化时扫描一次。详细说明见 [图片与 TF 卡制作](08-图片与TF卡制作.md)。

## 4. 按键与拨码

拨码分层优先级：**SW1 > SW2 > SW3 > SW4**。K2 在任意层都直接切下一张图。

| 拨码层 | K1 | K2 | K3 | K4 |
|---|---|---|---|---|
| **SW1 高**（图片层） | 转场模式循环：淡入淡出→右擦除→左擦除→下滑入 | 下一张 | 对比度循环：100→20→40→60→80→100% | 亮度循环：100→20→40→60→80→100% |
| **SW1 低、SW2 高**（自动层） | 转场模式循环 | 下一张 | 自动轮播开/关（1 秒/张） | — |
| **SW1 低、SW2 低、SW3 高**（音频层） | 音频播放/暂停 | 下一张 | 音量峰值条显示开/关 | 32 段频谱显示开/关 |
| SW1~SW3 均低（SW4 保留） | — | 下一张 | — | — |

> 只有 SW1 低、SW2 高时才能开启自动轮播；进入其它层会强制关闭轮播。

### 数码管

- SW2 高：显示 6 位播放计数（`shown_bcd`）
- SW2 低：显示一位 SD 状态码（原例程逻辑）
- 数码管扫描时钟为 50MHz

## 5. UART 标语协议

| 项目 | 参数 |
|---|---|
| 波特率 | 115200，8N1，无流控 |
| 电平 | 3.3V TTL（板载 USB-UART） |
| 结束符 | `\n` 或 `\r` |
| 编码 | ASCII，最多 32 字节；超过 31 字符自动滚动 |
| 控制命令 | `left`：从右向左滚动；`right`：从左向右滚动 |
| 内容更新 | 其它非空行作为新标语；内容更新后默认静态显示，过长自动滚动 |

示例（串口助手发送，勾选“加回车换行”）：

```
left
FPGA MULTIMEDIA PLAYER
right
```

## 6. 音频与可视化

- 上电检测到合法 WAV 后自动播放，HDMI 内嵌音频输出
- SW3 层 K1 暂停/恢复；暂停时 I2S 输出静音，FIFO/ASRC 状态冻结
- SW3 层 K3 显示音量峰值条（峰值保持 + 缓慢回落）
- SW3 层 K4 显示 32 段频谱：Goertzel 1024 点窗（约 21.3ms），频段约 47Hz~16kHz，对数分布
- 频谱/音量条叠加在视频之上，不改变上下栏原有显示逻辑
